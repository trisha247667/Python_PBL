# Phase 1: Data Collection

## Objective
To gather and organize the dataset required for the Email Spam Detection system.

## Dataset Details
- **Source:** Kaggle / UCI Machine Learning Repository
- **Format:** CSV (Comma Separated Values)
- **Features:** Contains 'v1' (Label: ham/spam) and 'v2' (Message text).

## Files in this phase
- `spam.csv`: The raw dataset.
