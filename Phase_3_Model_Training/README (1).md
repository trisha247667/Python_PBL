# Phase 3: Model Training

## Objective
To train machine learning models using the preprocessed numerical data to classify emails as 'Spam' or 'Ham'.

## Process
1. **Data Splitting**: Dividing the TF-IDF feature matrix into training and testing sets.
2. **Logistic Regression**: Training a probabilistic model to classify the text.
3. **Support Vector Machine (SVM)**: Training a model to find the optimal boundary between classes.

## Code Preview
The `model_training.ipynb` file contains the implementation of these algorithms using `scikit-learn`.
